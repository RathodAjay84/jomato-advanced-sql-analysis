Jomato Advanced SQL Analysis (MSSQL)
📌 Overview
This project focuses on advanced SQL-based analysis of a restaurant dataset (Jomato). It demonstrates the use of core and advanced SQL concepts to extract meaningful business insights and simulate real-world data analytics tasks.

🎯 Objectives

Analyze restaurant data using SQL queries
Apply advanced SQL concepts for data processing
Generate insights on ratings, costs, and restaurant distribution
Simulate real-world data analytics workflows


🛠️ Tools & Technologies

Microsoft SQL Server (MSSQL)
SQL (Structured Query Language)
VS Code


📊 Key SQL Concepts Implemented
🔹 Data Operations

BULK INSERT (CSV data import)
Data filtering and transformation

🔹 Advanced SQL Features

Stored Procedures
Transactions (COMMIT & ROLLBACK)
Window Functions (ROW_NUMBER)
Views for reusable queries
Triggers for event-based actions

🔹 Query Techniques

CASE statements
Aggregations (SUM, COUNT, AVG)
ORDER BY & TOP queries

🔍 Analysis Performed

Filtered restaurants based on table booking availability
Updated cuisine categories using transactions and rollback
Ranked restaurant areas using window functions
Generated top-rated restaurant insights
Created reusable views for high-rating analysis
Implemented trigger for insert operations


📈 Key Insights

Identified top-rated restaurants and areas
Observed distribution of restaurant types and cuisines
Demonstrated how SQL can be used for structured data analysis
